# 第三者 AI サービスへのデータ送信に関する通知

バージョン：v26.11　　改定日：2026.11.01

PalmiAgent はローカル優先の AI ツールです。チャット、添付ファイル、ツール結果を受信、保存、分析する独自のクラウドモデルサーバーを運営しておらず、あなたが操作または必要な許可を行っていない状態で、AI 処理のためにこれらの情報を独自に収集してアップロードすることもありません。次の手順でモデルを設定し、AI リクエストを開始し、関連する内容をタスクに含めた場合に限り、そのリクエストの実行に必要な内容が、あなた自身が選択した第三者 AI モデルサービスへ送信されます。

## 1. 送信される可能性があるデータ

1. あなたが能動的に入力したメッセージ、プロンプト、指示、およびモデルが現在のリクエストを理解して完了するために必要な過去のメッセージ、会話コンテキスト、タスク状態。App を開く、画面に留まる、またはバックグラウンドへ移動するだけで、現在のリクエストと無関係なチャットが自動的にアップロードされることはありません；
2. 現在のタスクへ明示的に追加した画像、文書、その他のファイル、およびモデルが添付内容を理解するための抽出テキスト、OCR 結果、ファイル形式情報、必要な要約。リクエストへ追加していない他のローカルファイルが、この理由により送信されることはありません；
3. 該当する iOS システム権限を別途許可し、対応するツールを明示的に呼び出した後、現在のタスクへ含めたカレンダー、リマインダー、連絡先、位置情報、写真、その他のツール結果。システム権限の許可自体はデータ送信への同意ではなく、現在の AI リクエストで実際に使用される結果のみが送信される可能性があります；
4. 現在のリクエストを構成、完了、またはエラーから復旧するために必要なシステム指示、ツール定義と結果、モデル識別情報、生成パラメータ、技術情報。これらは、あなたが開始したタスクを第三者モデルが正しく処理するために使用されます。

## 2. 受信者

受信者は、次の手順であなた自身が選択または入力して確認する第三者 AI モデルサービスと、その API エンドポイントの運営者であり、PalmiAgent ではありません。App は本通知において特定のサービスを事前選択、推奨、または示唆せず、まだ完了していない設定も表示しません。設定後、あなたが開始した AI リクエストに含まれる内容は、そのサービス運営者が管理するインターフェースへネットワーク経由で送信されます。具体的な法人運営者、サーバー地域、実際のデータ処理者は、最終的に選択したサービスとその規約によって決まります。サービスの身元、プライバシーポリシー、データ処理規則を確認できない、または信頼できない場合は、設定や内容の送信を行わないでください。

## 3. 利用目的

送信内容は、モデル回答の生成、選択した画像やファイルの理解、依頼した Agent タスクの実行、およびそのリクエストを完了するために必要なコンテキストの維持など、あなたが能動的に開始したリクエストの処理にのみ使用されます。第三者サービスは、自身のプライバシーポリシー、利用規約、アカウント設定に従って、データを記録、審査、保持、上流処理者へ転送、または削除する場合があります。PalmiAgent は、第三者の保持期間、学習利用、越境処理、削除方法を決定できません。送信後のアクセス、訂正、エクスポート、削除の要求は、そのサービス運営者が提供する窓口を通じて行う必要があります。

## 4. 端末内処理の範囲

PalmiAgent は、上記 AI リクエスト内容を中継、受信、または集中保存する独自のクラウドモデルサーバーを運営していません。現在の構成では、モデルリクエストはあなたの端末から、あなたが設定した第三者エンドポイントへ送信されます。App は利用する機能に応じてワークスペース、会話、設定を端末内に保存する場合がありますが、App を開いただけで現在のリクエストと無関係な個人情報を能動的に収集してアップロードすることはありません。連絡先、カレンダー、写真、位置情報などの iOS 権限は機能の利用時にシステムから別途求められます。本通知に基づく許可は、AI タスクへ明示的に含めた内容を、その後に選択する第三者モデルサービスへ送信することだけを対象とします。
