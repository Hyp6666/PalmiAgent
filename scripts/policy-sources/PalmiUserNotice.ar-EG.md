# إشعار Palmi بشأن الخصوصية وخدمات الذكاء الاصطناعي التابعة لجهات خارجية

مستند للقراءة والإقرار قبل تكوين النموذج لأول مرة

الإصدار: v26.7  
تاريخ الإصدار: 2026.07.01  
الفئة المستهدفة: مستخدمو تطبيق Palmi / PalmiAgent للأجهزة المحمولة

**مهم:** اقرأ هذا المستند قبل تكوين نموذج. يعني اختيار «قرأت وأوافق» أنك تفهم وتقر بمسارات تدفق البيانات وحدود خدمات الجهات الخارجية والتنبيهات المتعلقة بالمعلومات الحساسة ومسؤوليات الاختيار الخاصة بالمستخدم الموضحة هنا. ولا يعني ذلك أنك قبلت أي شروط لجهة خارجية لم تُعرض عليك. الشروط الرسمية لخدمات الجهات الخارجية هي الصفحات الحالية التي تنشرها تلك الخدمات.

## 1. الغرض والنطاق

هذا المستند هو إشعار مستخدم Palmi ‏(PalmiAgent) الذي يُعرض قبل تكوين النموذج لأول مرة. يشرح مسارات تدفق البيانات المحتملة بين التطبيق المحلي وخدمات النماذج التي يختارها المستخدم وأذونات النظام وأدوات الجهات الخارجية، ويطلب من المستخدم إقرارًا صريحًا قبل المتابعة.

هذا المستند ليس سياسة الخصوصية لأي مزود نماذج. ولا يحل محل شروط الخدمة أو سياسة الخصوصية أو اتفاقية المطور أو اتفاقية معالجة البيانات أو سياسة الاستخدام المقبول أو ترخيص النموذج أو قواعد السلامة الخاصة بأي مزود نماذج أو مزود خدمات سحابية أو مجمّع نماذج أو بوابة مؤسسية أو خدمة نظام أو نشر محلي تابع لجهة خارجية.

Palmi تطبيق وكلاء يعتمد على المعالجة المحلية أولًا، وواجهة للاتصال بالنماذج. يحدد النموذج الذي تختاره، وعنوان URL الأساسي الذي تدخله، ومفتاح API الذي تستخدمه، والمحتوى الذي ترسله، وأذونات النظام أو الأدوات التي تفعّلها، ما إذا كانت البيانات تغادر جهازك ومن يعالجها.

## 2. معالجة البيانات محليًا في تصميم المنتج الحالي

وفق تصميم المنتج الحالي، لا تشغّل Palmi قاعدة بيانات مركزية خاصة بها على خادم لمحتوى محادثاتك أو ملفات مساحة العمل أو المرفقات أو مفاتيح API. تُخزّن المشروعات والمحادثات وملفات مساحة العمل والمرفقات وسجلات التشغيل وذاكرات التخزين المؤقت والتفضيلات أساسًا في حاوية التطبيق على جهازك. ويُفترض تخزين بيانات اعتماد النماذج في Keychain النظام أو مخزن آمن مكافئ لبيانات الاعتماد.

تُنفّذ عادةً على الجهاز عمليات التعرف الضوئي المحلي على النصوص (OCR) ومعاينة الملفات وقراءة مساحة العمل والكتابة فيها وPython المضمّن وذاكرات التخزين المؤقت المحلية وإدارة المحادثات وتنظيف البيانات. وما لم تكوّن نموذجًا بعيدًا أو بحثًا بعيدًا أو خدمة ملفات بعيدة أو مزامنة سحابية أو مشاركة/تصديرًا أو ميزة أخرى تابعة لجهة خارجية، فإن Palmi نفسها لا ترسل تلك المواد عادةً إلى خادم بعيد تشغّله Palmi.

قد تعالج الأنظمة على مستوى الجهاز أو iCloud أو النسخ الاحتياطي للنظام أو تشخيص الأعطال أو App Store أو إدارة الأجهزة المحمولة المؤسسية أو وكلاء الشبكة أو شبكات VPN أو أدوات الأمان أو عمليات التصدير التي يبدأها المستخدم البيانات وفق قواعد Apple أو مسؤول المؤسسة أو خدمة الشبكة أو جهة خارجية تختارها. لا تتحكم Palmi في تلك العمليات على مستوى النظام أو التي يختارها المستخدم.

## 3. متى قد تغادر البيانات الجهاز

عندما تكوّن وتستخدم خدمة نماذج بعيدة أو مجمّع نماذج أو نقطة نهاية مستضافة سحابيًا أو بوابة مؤسسية أو نقطة نهاية مخصصة متوافقة مع OpenAI، فقد تُرسل إلى تلك الخدمة المطالبات والسياق وملخصات الملفات والصور ونتائج الأدوات وتكوين أدوار النماذج وأجزاء تعليمات النظام وسجل المحادثات ومعلومات الأخطاء والبيانات الوصفية اللازمة للطلبات.

عندما تفعّل البحث على الويب أو قراءة الويب أو الخرائط أو البريد أو الرسائل أو الهاتف أو التقويم أو التذكيرات أو جهات الاتصال أو الموقع أو الكاميرا أو الصور أو التعرف على الكلام أو الإشعارات أو Spotlight أو توجيه النظام أو قدرات أدوات أخرى، فقد تعالج البيانات ذات الصلة خدمة النظام أو مزود البحث أو الموقع الإلكتروني أو خدمة الحساب أو بيئة المؤسسة أو خدمة الشبكة المعنية.

عندما تستورد ملفًا أو تفتحه أو تنسخه أو تشاركه أو تصدّره أو ترسله أو ترفعه، أو تطلب من وكيل تنفيذ إجراء خارجي عليه، فقد يُكتب الملف أو محتواه في موقع تختاره، أو يُرسل إلى تطبيق أو مزود خدمة أو جهة اتصال تختارها، أو يدخل في ذاكرات التخزين المؤقت وسجلات النظام المعني.

يتطلب نقل البيانات عبر الشبكة عادةً وجود اتصال. وقد تعالج شركات الاتصالات ومزودو DNS والوكلاء وشبكات VPN والبوابات وجدران الحماية ومنتجات الأمان المؤسسية أو خدمات الجهات الخارجية البيانات الوصفية للشبكة وفق قواعدها الخاصة.

## 4. خدمات النماذج ونقاط النهاية المتوافقة مع OpenAI وحدود المسؤولية

يصف مصطلح «متوافق مع OpenAI» فقط التشابه في شكل نقطة النهاية أو المصادقة أو تنسيق الطلبات أو بنية الرسائل أو التدفق أو تنسيق استدعاءات الأدوات. ولا يعني أن OpenAI تشغّل الخدمة، ولا أن الخدمة تتبع قواعد OpenAI نفسها فيما يتعلق بالأمان أو الاحتفاظ بالبيانات أو التدريب أو الحذف أو نقل البيانات عبر الحدود أو المنازعات أو المسائل القانونية.

قد تعمل خدمات النماذج ومزودو الخدمات السحابية ومجمّعات النماذج والبوابات المؤسسية والخدمات المستضافة ذاتيًا التابعة لجهات خارجية بوصفها متحكمين مستقلين في البيانات أو معالجين أو متحكمين مشتركين أو مزودي بنية تحتية أو مستضيفي نماذج. وتحكم سياساتها الحالية واتفاقيات الحساب لديها كيفية تسجيل البيانات والاحتفاظ بالمدخلات والمخرجات وإجراء مراجعات السلامة واستخدام البيانات لتدريب النماذج وتوجيه البيانات إلى نماذج أخرى والتعامل مع طلبات الحذف أو الاستجابة لطلبات الجهات الحكومية أو التنظيمية.

لا تستطيع Palmi التحقق نيابةً عنك من ملكية نقطة نهاية تدخلها أو مصدر مفتاح API أو صلاحية الحساب أو منطقة الخدمة أو مسؤولية الفوترة أو مدة الاحتفاظ بالبيانات أو إعداد التدريب أو تكوين عدم الاحتفاظ بالبيانات أو شروط حماية البيانات المؤسسية أو المعالج الفعلي للنموذج في سلسلة تقديم الخدمة. ينبغي لك التأكد من هذه الأمور قبل الاستخدام.

## 5. المحتوى الحساس ومواد المؤسسات وبيانات الآخرين

ينبغي ألا ترسل كلمات المرور أو مفاتيح API أو المفاتيح الخاصة أو أرقام الهوية أو بيانات البطاقات المصرفية أو المعلومات الصحية أو معلومات القاصرين أو الموقع الدقيق أو جهات الاتصال أو سجلات المحادثات أو بيانات العملاء أو الأسرار الموجودة في الشفرة المصدرية أو الأسرار التجارية أو الأبحاث غير المنشورة أو المحتوى المحمي باتفاقية عدم إفصاح أو البيانات الخاضعة للتنظيم أو أي مادة قد تضر بحقوق شخص آخر، إلا إذا كانت لديك أذونات كافية وأساس قانوني ومراجعة أمنية.

إذا كنت تستخدم Palmi بالنيابة عن شركة أو مدرسة أو مختبر أو فريق مشروع أو عميل أو أحد أفراد العائلة أو أي جهة أخرى، فينبغي لك التأكد من أنك مخوّل بتكوين خدمات النماذج وإرسال المحتوى المعني ومنح أذونات النظام واستدعاء الأدوات ورفع الملفات أو تصديرها، ومن امتثالك لمتطلبات تلك المؤسسة المتعلقة بتصنيف البيانات والسرية والامتثال والمشتريات والموافقات الأمنية.

إذا لم تكن متأكدًا مما إذا كان يجوز إرسال فئة من المعلومات إلى نموذج أو خدمة تابعة لجهة خارجية، فلا ترسلها بشكل افتراضي. فكّر في التنقيح لإزالة المعلومات الحساسة أو التلخيص أو إخفاء الهوية أو المعالجة المحلية أو الحصول على موافقة داخلية أو استخدام خدمة مؤسسية تستوفي متطلبات الامتثال المعمول بها.

## 6. استدعاءات الأدوات وأذونات النظام والإجراءات الخارجية

قد تقترح ميزات الوكلاء في Palmi أو تبدأ قراءة ملفات أو توليدها أو إجراء تغييرات في مساحة العمل أو البحث على الويب أو الوصول إلى التقويم والتذكيرات وجهات الاتصال والموقع والصور والكاميرا والكلام وتطبيقات النظام ومسودات الرسائل، أو تنفيذ إجراءات أخرى في النظام. قد تتطلب الأدوات المختلفة أذونات iOS أو تأكيد المستخدم أو ترخيص حساب تابع لجهة خارجية أو موافقة بموجب سياسة المؤسسة.

ينبغي أن يراجع إنسان قبل التنفيذ أي إجراء قد يؤثر في نظام خارجي أو شخص آخر أو أصول الحساب أو الجداول أو حالة الملفات أو إرسال الرسائل أو المشتريات أو المدفوعات أو النشر التشغيلي أو الحذف أو الإفصاح العلني. قد تكون مخرجات النماذج غير مكتملة أو غير دقيقة أو قديمة أو مختلقة أو متحيزة أو غير متوافقة مع قصدك.

تزداد المخاطر بدرجة كبيرة إذا فعّلت الموافقات التلقائية أو التنفيذ على دفعات أو تنفيذ البرامج النصية أو أتمتة الويب أو توجيه النظام أو تكاملات الأدوات المؤسسية. استخدم هذه القدرات فقط في المهام الموثوقة والبيئات التي يمكن التراجع فيها عن الإجراءات.

## 7. إدارة البيانات المحلية وسحب الإذن والحذف

يمكنك إدارة البيانات المحلية وبيانات حسابات الجهات الخارجية من خلال إدارة البيانات داخل التطبيق أو إعدادات النظام أو إعدادات أذونات iOS أو إعادة ضبط Keychain أو بيانات الاعتماد أو لوحات تحكم المزودين أو بوابات حسابات الجهات الخارجية أو مسؤولي المؤسسة أو تذاكر دعم مزودي الخدمات السحابية أو إلغاء تثبيت التطبيق.

يؤثر مسح مساحة عمل Palmi المحلية أو ذاكرات التخزين المؤقت أو التفضيلات أو بيانات اعتماد النماذج فقط في البيانات الموجودة على الجهاز أو النسخ التي تحتفظ بها Palmi. ولا يحذف تلقائيًا البيانات التي أُرسلت بالفعل إلى خدمات النماذج أو مزودي البحث أو المواقع الإلكترونية أو مزودي الخدمات السحابية أو مجمّعات الخدمات أو البوابات المؤسسية أو خدمات النظام أو التطبيقات الأخرى التابعة لجهات خارجية. يجب التعامل مع الوصول والتصحيح والتصدير والحذف وإيقاف الاستخدام في التدريب وعناصر التحكم في الذاكرة أو الاحتفاظ بالسجلات لدى الجهة الخارجية وفق سياسة ذلك المزود وأدوات الحساب لديه.

قد يظل حذف التطبيق أو إلغاء تثبيته متأثرًا بالنسخ الاحتياطية للنظام وإدارة الأجهزة المؤسسية والسجلات والملفات المُصدّرة والنسخ المشتركة ومدد احتفاظ الجهات الخارجية بالبيانات والتزامات الحفظ القانوني.

## 8. تنبيه بشأن مخرجات الذكاء الاصطناعي والمخاطر المهنية

لا تُعد مخرجات النماذج مشورة قانونية أو طبية أو مالية أو استثمارية أو ضريبية، ولا مشورة في السلامة الهندسية أو الصحة النفسية أو التوظيف أو الهجرة أو التعليم أو غيرها من المجالات المهنية. في السيناريوهات عالية المخاطر أو المهنية، استشر متخصصًا مؤهلًا وتحقق من النتيجة بصورة مستقلة.

قد تولّد النماذج حقائق غير صحيحة أو شفرة برمجية معيبة أو استشهادات خاطئة أو نصائح أمنية مضللة أو خططًا غير قابلة للتنفيذ أو سياسات قديمة أو روابط زائفة أو محتوى غير ملائم. ينبغي أن تقرر بعناية ما إذا كنت ستستخدم مخرجات النموذج أو توزّعها أو تنفذها أو تقدمها أو تعتمد عليها.

Palmi أداة وواجهة لسير العمل. ولا تضمن أن أي نموذج أو نقطة نهاية أو أداة أو مصدر بحث أو خدمة نظام أو تكوين مستخدم تابع لجهة خارجية سيكون متاحًا أو دقيقًا أو آمنًا أو ممتثلًا أو مناسبًا لغرض معين في جميع الأوقات.

## 9. مراجع سياسات خدمات النماذج الشائعة

تسرد القائمة أدناه مراجع سياسات قد تكون ذات صلة بخيارات Palmi السريعة الحالية، أو المزودين المتوافقين مع OpenAI الذين لا تزال إعداداتهم محفوظة أو الشائعين، أو مجمّعات النماذج، أو خدمات النماذج المخصصة. الروابط مراجع عامة أو مداخل رسمية للوحات التحكم جُمعت لإصدار هذا المستند. قد يعرض المزودون شروطًا مختلفة حسب البلد أو المنطقة أو نوع الحساب أو اتفاقية المؤسسة أو منتج API أو النموذج أو مسار الاستضافة أو المزود الأصلي للنموذج. اعتمد قبل الاستخدام على صفحة المزود الحالية.

- منصة BigModel / Zhipu المفتوحة: https://open.bigmodel.cn/

### DeepSeek

أحد خيارات المزودين السريعة التي يمكن اختيارها حاليًا في Palmi؛ وقد يُستخدم أيضًا عبر API الرسمي أو مجمّع نماذج أو نقطة نهاية مخصصة.

- سياسة خصوصية DeepSeek: https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html

### نقطة نهاية مخصصة متوافقة مع OpenAI

عنوان URL أساسي ومفتاح API واسم نموذج يقدمها المستخدم. قد تكون الخدمة الفعلية مزودًا رسميًا أو مجمّع نماذج أو مستضيفًا سحابيًا أو بوابة مؤسسية أو خادمًا محليًا أو خدمة مستضافة ذاتيًا.

يصف «متوافق مع OpenAI» شكل API فقط؛ ولا يعني أن OpenAI تشغّل نقطة النهاية أو أن قواعد الخصوصية والاحتفاظ بالبيانات والتدريب والحذف والنقل هي نفسها.

راجع السياسة الحالية لمالك نقطة النهاية أو بوابة المؤسسة أو النظام المستضاف ذاتيًا قبل إرسال البيانات.

1. أفهم أن Palmi تطبيق وكلاء يعتمد على المعالجة المحلية أولًا وواجهة للاتصال بالنماذج، وأن التصميم الحالي لا يستخدم قاعدة بيانات مركزية على خادم تشغّله Palmi لمحتوى المحادثات أو ملفات مساحة العمل أو المرفقات أو مفاتيح API.

3. أفهم أن احتفاظ الجهات الخارجية بالبيانات واستخدامها للتدريب وتوجيهها إلى مزودين أصليين ونقلها عبر الحدود وطلبات الحذف وأمان الحساب والتكاليف وتسوية المنازعات تخضع لسياسات تلك الجهة الحالية واتفاقي معها.

5. إذا لم أوافق على هذا الإشعار أو لم أتحقق من سياسة المزود الذي اخترته، فيمكنني إيقاف تكوين النموذج أو الرجوع وتغيير اختياري.
