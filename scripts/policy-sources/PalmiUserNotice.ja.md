## 1. 本書の性質と適用範囲

本書は、Palmiが初回のモデル設定前にユーザーへ表示する「プライバシーおよび第三者 AI サービスに関するお知らせ」です。端末上のアプリ、ユーザーが選択したモデルサービス、システム権限、第三者ツールの間で生じうるデータの流れを説明し、モデル設定を続ける前にユーザーの明示的な確認を求めるものです。

本書は特定のモデル提供者のプライバシーポリシーではなく、第三者のモデル提供者、クラウド事業者、モデルアグリゲーター、企業ゲートウェイ、システムサービス、ローカル環境の利用規約、プライバシーポリシー、開発者契約、データ処理契約、許容される利用に関するポリシー、モデルライセンス、安全規則に代わるものでもありません。

Palmi は、ローカル処理を優先する Agent アプリであり、モデル接続のためのインターフェースです。どのモデルを選ぶか、どの Base URL を入力するか、どの API キーを使うか、どの内容を送信するか、どのシステム権限やツールを有効にするかによって、データが端末の外へ出るかどうか、また誰が処理するかが決まります。

## 2. 現在の製品設計におけるローカルでのデータ処理

現在の製品設計では、Palmi はチャット内容、ワークスペースのファイル、添付ファイル、API キーを集中管理する自社サーバー側データベースを運用していません。プロジェクト、会話、ワークスペースのファイル、添付ファイル、実行記録、キャッシュ、設定は主に端末上のアプリコンテナに保存されます。モデルの認証情報は、システムのキーチェーンまたは同等の安全な認証情報ストアに保存されるべきものです。

ローカル OCR、ファイルのプレビュー、ワークスペースの読み書き、組み込み Python、ローカルキャッシュ、会話の管理、データの消去は、通常は端末上で実行されます。リモートモデル、リモート検索、リモートファイルサービス、クラウド同期、共有・書き出し、その他の第三者機能を設定しない限り、これらの内容が Palmi 自身によって Palmi の運営するリモートサーバーへ送信されることは通常ありません。

端末レベルのシステム、iCloud やシステムのバックアップ、クラッシュ診断、App Store、企業のモバイルデバイス管理、ネットワークプロキシ、VPN、セキュリティツール、ユーザーが自ら書き出したファイルは、Apple、組織の管理者、ネットワーク事業者、またはユーザーが選択した第三者の規則に従ってデータを処理する場合があります。Palmi はこれらのシステムレベルの処理やユーザーが選択した処理を管理できません。

## 3. データが端末の外へ出る場合

リモートのモデルサービス、モデルアグリゲーター、クラウドでホストされたエンドポイント、企業ゲートウェイ、またはカスタムの OpenAI 互換エンドポイントを設定して使用する場合、モデルに送るプロンプト、コンテキスト、ファイルの要約、画像、ツールの結果、モデルの役割設定、システム指示の一部、会話履歴、エラー情報、必要なリクエストのメタデータが当該サービスへ送信されることがあります。

ウェブ検索、ウェブページの読み取り、地図、メール、メッセージ、電話、カレンダー、リマインダー、連絡先、位置情報、カメラ、写真、音声認識、通知、Spotlight、システムルーティング、その他のツール機能を有効にした場合、関連する内容は該当するシステムサービス、検索提供者、ウェブサイト、アカウントサービス、企業環境、ネットワークサービスによって処理されることがあります。

ファイルを読み込む、開く、コピーする、共有する、書き出す、送信する、アップロードする、または Agent にファイルに対する外部操作を指示した場合、そのファイルや内容は、ユーザーが選んだ場所に書き込まれたり、ユーザーが選んだアプリ、提供者、連絡先へ送られたり、該当するシステムのキャッシュやログに記録されたりすることがあります。

通信には通常ネットワーク接続が必要です。通信事業者、DNS 提供者、プロキシ、VPN、ゲートウェイ、ファイアウォール、企業向けセキュリティ製品、第三者の SDK やサービスは、それぞれの規則に従ってネットワークのメタデータを処理することがあります。

## 4. モデルサービス、OpenAI 互換エンドポイント、責任の範囲

「OpenAI 互換」とは、エンドポイントの形式、認証方式、リクエスト形式、メッセージ構造、ストリーミング、ツール呼び出しの形式が OpenAI のエコシステムに似ていることを示すにすぎません。当該サービスを OpenAI が運営していることを意味するものではなく、セキュリティ、データ保持、学習への利用、削除、越境移転、紛争解決、準拠法の規則が OpenAI と同じであることを意味するものでもありません。

第三者のモデルサービス、クラウド事業者、モデルアグリゲーター、企業ゲートウェイ、セルフホストのサービスは、それぞれ独立した管理者、処理者、共同管理者、インフラ提供者、またはモデルのホストとして行動する場合があります。ログの記録、入出力の保持、安全性審査、モデル学習への利用、上流モデルへの転送、削除請求への対応、政府や規制当局からの要請への対応は、各社の最新のポリシーとアカウント契約に従います。

Palmi は、ユーザーが入力したエンドポイントの所有者、API キーの出所、アカウントの権限、サービス地域、請求責任、保持期間、学習に関する設定、データ非保持の設定、企業向けデータ保護条項、実際の上流モデルの処理者を、ユーザーに代わって確認することはできません。これらは利用前にご自身でご確認ください。

## 6. ツールの呼び出し、システム権限、外部への操作

Palmi の Agent 機能は、ファイルの読み取り、ファイルの生成、ワークスペースの変更、ウェブ検索、カレンダー・リマインダー・連絡先・位置情報・写真・カメラ・音声へのアクセス、システムアプリの起動、メッセージの下書き作成、その他のシステム操作を提案または実行することがあります。ツールによっては、iOS の権限、ユーザーの確認、第三者アカウントの認可、組織のポリシーによる許可が必要です。

外部のシステム、他者、アカウント上の資産、予定、ファイルの状態、メッセージの送信、購入、支払い、デプロイ、削除、公開に影響しうる操作は、実行前に人が確認してください。モデルの出力は、不完全、不正確、古い、事実に基づかない、偏っている、またはユーザーの意図と異なる場合があります。

自動承認、一括実行、スクリプトの実行、ウェブの自動操作、システムルーティング、企業ツールとの連携を有効にすると、リスクは大きく高まります。これらの機能は、信頼できる作業と元に戻せる環境でのみ使用してください。

## 7. ローカルデータの管理、同意の撤回、削除

ローカルのデータと第三者アカウントのデータは、アプリ内のデータ管理、システム設定、iOS の権限設定、キーチェーンや認証情報のリセット、提供者のコンソール、第三者アカウントの管理画面、組織の管理者、クラウド事業者への問い合わせ、アプリの削除などの方法で管理できます。

Palmi のローカルのワークスペース、キャッシュ、設定、モデルの認証情報を消去しても、影響するのは端末上のデータまたは Palmi が保持する複製のみです。第三者のモデルサービス、検索提供者、ウェブサイト、クラウド事業者、アグリゲーター、企業ゲートウェイ、システムサービス、その他のアプリへすでに送信されたデータは自動的には削除されません。第三者側でのアクセス、訂正、書き出し、削除、学習の停止、メモリやログ保持の設定は、当該提供者のポリシーとアカウントツールに従って行ってください。

アプリを削除またはアンインストールしても、システムのバックアップ、企業のデバイス管理、ログ、書き出したファイル、共有した複製、第三者の保持期間、法的な保存義務の影響を受ける場合があります。

モデルは、誤った事実、不具合のあるコード、誤った引用、誤解を招くセキュリティ上の助言、実行できない計画、古いポリシー、存在しないリンク、不適切な内容を生成することがあります。モデルの出力を利用、配布、実行、提出、またはそれに依拠するかどうかは、慎重に判断してください。

Palmi はツールおよびワークフローのためのインターフェースです。第三者のモデル、エンドポイント、ツール、検索ソース、システムサービス、ユーザーの設定が常に利用可能で、正確、安全、適法であること、または特定の目的に適合することを保証するものではありません。
