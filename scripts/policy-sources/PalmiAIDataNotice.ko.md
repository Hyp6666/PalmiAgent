# 제3자 AI 서비스 데이터 고지서

버전: v26.11  버전 일자: 2026.11.01

PalmiAgent는 로컬 우선 AI 도구입니다. 채팅, 첨부 파일 또는 도구 결과를 수신, 저장하거나 분석하는 자체 클라우드 모델 서버를 운영하지 않으며, 사용자가 직접 조작하거나 관련 권한을 부여하지 않은 상태에서 AI 처리를 위해 이러한 정보를 독자적으로 수집하고 업로드하지도 않습니다. 다음 단계에서 모델 설정을 완료하고, AI 요청을 직접 시작하고, 관련 콘텐츠를 작업에 포함한 경우에만 해당 요청 수행에 필요한 콘텐츠가 사용자가 직접 선택한 제3자 AI 모델 서비스로 전송됩니다.

## 1. 전송될 수 있는 데이터

1. 사용자가 직접 입력한 메시지, 프롬프트와 지침 및 모델이 현재 요청을 이해하고 완료하는 데 필요한 이전 메시지, 대화 컨텍스트와 작업 상태. App을 열거나 화면에 머무르거나 백그라운드로 전환하는 것만으로 현재 요청과 무관한 채팅이 자동 업로드되지는 않습니다;
2. 현재 작업에 명시적으로 추가한 이미지, 문서와 기타 파일 및 모델이 첨부 내용을 이해하는 데 필요한 추출 텍스트, OCR 결과, 파일 형식 정보 또는 필요한 요약. 요청에 추가하지 않은 다른 로컬 파일은 이러한 이유로 전송되지 않습니다;
3. 해당 iOS 시스템 권한을 별도로 부여하고 관련 도구를 명시적으로 호출한 후 현재 작업에 포함한 캘린더, 미리 알림, 연락처, 위치, 사진 또는 기타 도구 결과. 시스템 권한 부여 자체는 데이터 전송에 대한 동의가 아니며 현재 AI 요청에서 실제 사용하는 결과만 전송될 수 있습니다;
4. 현재 요청을 구성, 완료하거나 오류에서 복구하는 데 필요한 시스템 지침, 도구 정의와 결과, 모델 식별 정보, 생성 매개변수 및 기술 정보. 이러한 정보는 사용자가 시작한 작업을 제3자 모델이 올바르게 처리하도록 하는 데 사용됩니다.

## 2. 수신자

수신자는 다음 단계에서 사용자가 직접 선택하거나 입력하고 확인하는 제3자 AI 모델 서비스 및 해당 API 엔드포인트 운영자이며 PalmiAgent가 아닙니다. App은 본 고지서에서 특정 서비스를 미리 선택, 추천 또는 암시하지 않으며 아직 완료하지 않은 설정도 표시하지 않습니다. 설정을 완료하면 사용자가 직접 시작한 AI 요청에 포함된 콘텐츠가 네트워크를 통해 해당 서비스 운영자가 관리하는 인터페이스로 전송됩니다. 구체적인 법적 운영 주체, 서버 지역 및 실제 데이터 처리자는 사용자가 최종 선택한 서비스와 그 약관에 따라 달라집니다. 서비스의 신원, 개인정보 처리방침 또는 데이터 처리 규칙을 확인할 수 없거나 신뢰하지 않는 경우 설정을 완료하거나 콘텐츠를 전송하지 마십시오.

## 3. 목적

전송 콘텐츠는 모델 응답 생성, 사용자가 선택한 이미지나 파일의 이해, 요청한 Agent 작업 수행 및 해당 요청 완료에 필요한 컨텍스트 유지 등 사용자가 직접 시작한 요청을 처리하는 목적으로만 사용됩니다. 제3자 서비스는 자체 개인정보 처리방침, 이용약관과 계정 설정에 따라 데이터를 기록, 검토, 보관, 상위 처리자에게 전달하거나 삭제할 수 있습니다. PalmiAgent는 해당 제3자의 보관 기간, 학습 사용, 국경 간 처리 또는 삭제 방식을 결정할 수 없습니다. 전송 후 데이터의 열람, 정정, 내보내기 또는 삭제 요청은 해당 서비스 운영자가 제공하는 경로를 통해 처리해야 합니다.

## 4. 기기 내 처리 범위

PalmiAgent는 위 AI 요청 콘텐츠를 중계, 수신하거나 중앙 집중식으로 저장하는 자체 클라우드 모델 서버를 운영하지 않습니다. 현재 구조에서는 모델 요청이 사용자의 기기에서 사용자가 설정한 제3자 엔드포인트로 전송됩니다. App은 사용 기능에 따라 작업 공간, 대화 및 설정을 기기에 로컬로 저장할 수 있지만 App을 열었다는 이유만으로 현재 요청과 무관한 개인정보를 능동적으로 수집하여 업로드하지 않습니다. 연락처, 캘린더, 사진, 위치 등의 iOS 권한은 기능 사용 시 시스템에서 별도로 요청됩니다. 본 고지서에 따른 허용은 사용자가 AI 작업에 명시적으로 포함한 콘텐츠를 이후 선택한 제3자 모델 서비스로 전송하는 경우에만 적용됩니다.
