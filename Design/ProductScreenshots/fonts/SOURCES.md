# Poster font resources

Downloaded on 2026-10-07 from the official [Google Fonts repository](https://github.com/google/fonts). The font binaries are unmodified; only the local filenames differ from the upstream filenames. Both fonts use the SIL Open Font License 1.1 and can be used in commercial artwork. The complete copyright notices and licenses are retained beside the fonts.

| Local file | Official source | Local license |
| --- | --- | --- |
| `SourceSerif4-Variable.ttf` | [Source Serif 4](https://github.com/google/fonts/blob/main/ofl/sourceserif4/SourceSerif4%5Bopsz%2Cwght%5D.ttf) | `SourceSerif4-OFL.txt` |
| `NotoSerifSC-Variable.ttf` | [Noto Serif SC](https://github.com/google/fonts/blob/main/ofl/notoserifsc/NotoSerifSC%5Bwght%5D.ttf) | `NotoSerifSC-OFL.txt` |

Source Serif 4 is a normal-style variable serif font with weight 200–900 (default 400) and optical size 8–60 (default 20). The binary is 1,209,508 bytes.

Noto Serif SC is a normal-style variable Simplified Chinese serif font with weight 200–900 (default 200). Its complete character coverage is retained, allowing revised poster copy to render without downloading further glyph subsets. The binary is 25,125,512 bytes.

Both are local TrueType files suitable for local `@font-face` loading or a native font renderer. No network font import is needed. Font table boundaries, variation axes, representative English and Chinese glyph coverage, and local Pillow font loading have been verified.
