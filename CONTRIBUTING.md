By submitting an issue, pull request, patch, or other contribution, you confirm
that you have the right to submit it and that your contribution is licensed
under the Apache License 2.0 unless a separate written agreement says otherwise.

Please do not submit:

- API keys, tokens, certificates, provisioning profiles, or private signing material;
- local agent instructions such as `AGENTS.md`, `CLAUDE.md`, or `.codex/`;
- internal spec drafts, private notes, or local reference repositories;
- code copied from another project unless its license permits reuse here and the source is clearly noted.
