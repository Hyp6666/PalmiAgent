# Media browsing and playback

Understand whether the user wants a video, song, podcast, novel, comic, live stream, or subscription.
Confirm the title, creator, language, edition, season, episode, chapter, and intended action when ambiguous.
Use the user's viewing country to choose a storefront and interpret licensing restrictions.
Ask the user before selecting a paid plan, rental, purchase, or recurring subscription.
Open a verified consumer entry and observe the current page before acting.
Search through observed controls, or use a verified query template with a URL-encoded query.
Read result titles, creators, dates, episode numbers, durations, and format before opening a match.
Inspect the detail page for availability, age restrictions, subtitles, dubbing, price, and account requirements.
Distinguish trailers, previews, excerpts, and free chapters from the complete work.
Treat a regional availability message, verification challenge, or playback error as the current result.
Do not infer successful playback from a catalog listing or an HTTP success code.
Observe player controls and current playback state before changing play, pause, volume, captions, or position.
Use fresh observation references after navigation or interaction.
Ask the user to confirm currency, billing period, renewal terms, and the selected plan before subscribing.
Hand off sign-in, age verification, security challenges, payment credentials, and browser permission prompts to the user.
After handoff, observe the page again and verify the account or playback state.
Confirm the exact work before saving, following, adding to a library, or changing an existing subscription.
Report the matched title, creator, edition or episode, source link, availability, and any observed access restriction.
Report a purchase or account change only when the resulting page confirms it.
