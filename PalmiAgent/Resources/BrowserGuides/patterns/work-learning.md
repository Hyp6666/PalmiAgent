# Work and Learning Workflow

Understand whether the user wants jobs, courses, document work, translation, or another online tool.
Use ask_user to resolve missing location, language, skill level, budget, deadline, and desired output.
For jobs, establish role, city, remote preference, experience, work eligibility, and salary currency.
For courses, establish prerequisites, teaching language, schedule, certificate needs, and total price.
For workspace tasks, establish the account, document, sharing audience, and requested edit scope.
Open a verified consumer entry and observe the current page before selecting controls.
Dismiss optional banners only when their effect is clear.
Use the current observation identifiers for search, filters, links, and form fields.
Confirm that results match the intended query, location, language, and active filters.
Read job duties, employer, salary period, application deadline, and application destination.
Read course provider, prerequisites, dates, access duration, assessment, and fees.
Compare relevant results using details visible on each result or detail page.
Hand off account login, passwords, verification codes, and payment fields to the user.
Observe again after handoff to confirm the account and page state.
Prepare application text or document edits within the user's requested scope.
Use ask_user before submitting applications, enrolling in paid courses, publishing, or changing sharing permissions.
Check the displayed destination, recipients, price, renewal terms, and final content before confirmation.
For online tools, confirm source files, output format, language pair, and preservation requirements.
Hand off file selection, downloads, complex canvas gestures, and unsupported rich text editing.
After an action, observe the completion state and check the resulting content.
Report the verified result, source links, account-dependent limitations, and any action still awaiting the user.
