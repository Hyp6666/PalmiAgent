# Local Services

Understand the requested service, city, neighbourhood, budget, timing, and number of people.
For home services, establish the service address, property size, access instructions, and scope.
For restaurant or salon appointments, establish the date, local time, party size, and preferences.
Open the consumer entry and observe the current region, language, and account state.
Use the user's chosen city or postcode before comparing available providers.
Search using visible controls or a verified search template, then observe the results.
Read provider profiles, service descriptions, prices, review dates, and availability.
Distinguish fixed prices from estimates, deposits, minimum charges, and requests for quotes.
Check the included work, materials, travel charges, and exclusions before recommending a provider.
Read cancellation, rescheduling, refund, and no-show terms for the selected appointment.
Use current observations for every interaction and observe again after changing filters.
Report when availability is a request awaiting confirmation rather than an instant booking.
Ask the user to confirm the provider, scope, address, time, total price, and relevant terms.
Treat publishing a job request, contacting a provider, or submitting a reservation as an external action.
Submit those actions only within the user's explicit authorization.
Hand off account login, identity checks, verification codes, and payment details to the user.
When an appointment requires an app or unsupported interaction, hand off the required step.
After the user returns, observe the page before continuing.
Verify confirmation text, provider, address, local date and time, and booking or request reference.
Report the outcome and source link, including whether the provider still needs to accept the request.
