# PP-OCRv6 Tiny OCR Assets

This directory bundles only the PP-OCRv6 Tiny ONNX assets used by PalmiAgent's
local OCR tool.

Source models:

- Text detection: `PaddlePaddle/PP-OCRv6_tiny_det_onnx`
- Text recognition: `PaddlePaddle/PP-OCRv6_tiny_rec_onnx`
